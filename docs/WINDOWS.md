# Установка и обслуживание в Windows

### Меню и автовосстановление Windows

Установщик открывает фиксированный экран: заголовок, статус операции и строка ввода обновляются на месте. Для выбора введите номер пункта и нажмите Enter. Длинные строки переносятся по ширине окна; при большом количестве сообщений видны последние строки. Можно изменить размер окна. При запуске с перенаправлением вывода используется обычный текстовый режим.


- **1** — установка и включение фоновой проверки; **2** — установка без изменения состояния фоновой задачи.
- **3** — диагностика, время последней проверки и пути журналов; **4** — отключение фоновой проверки.
- **5** — выбор Stable, PTB или Canary. По умолчанию выбран Stable.

Автовосстановление — задача Планировщика Windows **от имени текущего пользователя**, без пароля и прав администратора. После входа в Windows и каждые 2 минуты проверяет запуск Discord. Ждёт завершения обновления клиента и даёт плагину 3 минуты на запуск. Исправно работающий сеанс не обновляет и не перезапускает. При ручной первоначальной установке не запускайте Discord до её завершения.

После слетевшего загрузчика или неудачного запуска включённого плагина задача проверяет последний стабильный релиз BetterDiscord. Если исправление ещё не вышло, повторяет поиск раз в 15 минут, не переустанавливая ту же неработающую версию. Когда доступно исправление, скачивает проверенный официальный CLI, восстанавливает BetterDiscord и ждёт сигнала успешного запуска плагина. Отсутствующий файл плагина восстанавливает из локальной копии.

Если для восстановления нужно перезапустить открытый Discord, появляется окно с отсчётом **60 секунд** и кнопками **«Восстановить сейчас» / «Отложить на час»**. Без действий восстановление начинается после отсчёта; закрытие окна откладывает его. При начавшемся обновлении или смене сеанса Discord операция откладывается. Исправную установку не переустанавливает. Другие модификации автоматически не заменяет. Настройки, аккаунты, группы и переключатель включения плагина не изменяет; существующий файл плагина не понижает до старой версии. Перед намеренным удалением плагина отключите задачу пунктом **4**.

Файлы задачи и журнал последней проверки: %LOCALAPPDATA%/RedflagAutoMute/maintenance. Архив установки после этого можно удалить. После несовместимого обновления Discord задача ждёт исправленного релиза BetterDiscord и применяет его автоматически с предупреждением о перезапуске. Пока разработчики не выпустили исправление, восстановить совместимость невозможно. Сбой самого плагина или его намеренное отключение не исправляются переустановкой BetterDiscord. Плагин автоматически обновляется из стабильных GitHub Releases раз в 6 часов. Проверяются источник, SHA-256 и версия; настройки сохраняются, Discord не перезапускается. При неудачном запуске включённого плагина выполняется откат. Пункт 6 отключает автообновление отдельно от восстановления. Для старых установок нужно один раз запустить новый ZIP и выбрать пункт 1. Скрипты фоновой задачи обновляются установщиком, а не автоматически.


Журнал доставки обновлений: `%LOCALAPPDATA%/RedflagAutoMute/maintenance/plugin-update/state.json`.
